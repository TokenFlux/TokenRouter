# 数据共享预生成导出文件

## Summary

将数据共享管理端的批量下载改为“先生成导出文件，再从文件列表下载”。管理员在现有数据共享页选择记录或筛选结果后创建生成任务；后端异步把 JSONL/Zstd 文件写到本地目录并记录元数据；新板块展示任务状态和已生成文件，支持单独下载和手动删除。批量实时下载入口不再保留，避免再次触发超时路径。

## Key Changes

- 后端新增 `data_share_export_artifacts` 元数据表，迁移文件使用 `166_...sql` 前缀。
- 表字段包含：任务 ID、状态 `pending/running/completed/failed/deleted`、文件名、存储路径、编码、大小、sha256、筛选条件快照、记录数、错误信息、创建/开始/完成/删除时间。
- 新增本地导出目录配置，建议放在 `gateway.data_sharing_export.storage_dir`，默认解析到后端 `DATA_DIR/data-sharing-exports`。
- 新增导出任务服务：创建任务后后台执行现有 `ExportJSONL` 流程，写入临时文件，完成后原子重命名并更新元数据。
- 生成任务一次只产出一个文件，编码默认沿用现有批量导出的 `.jsonl.zst`；单条导出也改为生成任务，不走实时下载。
- 新增管理端接口：
  - `POST /api/v1/admin/data-sharing/exports`：按当前选择/筛选创建生成任务。
  - `GET /api/v1/admin/data-sharing/exports`：分页列出任务和文件。
  - `GET /api/v1/admin/data-sharing/exports/:id`：查看单个任务状态。
  - `GET /api/v1/admin/data-sharing/exports/:id/download`：仅完成状态可下载本地文件。
  - `DELETE /api/v1/admin/data-sharing/exports/:id`：手动删除文件并标记删除。
- 下载接口继续使用管理员鉴权；文件路径必须通过任务记录解析，禁止直接拼接用户输入路径。

## Frontend

- 在现有 `/admin/data-sharing` 页面新增“导出文件”板块，展示任务状态、文件名、大小、记录数、创建时间、完成时间、失败原因和操作按钮。
- 原“导出已选 JSONL”按钮改为“生成导出文件”，调用新建任务接口，成功后提示并刷新导出文件列表。
- 行内“下载”按钮也改为为该 session 创建生成任务。
- 已完成任务显示“下载”和“删除”；处理中显示进度态文案；失败任务显示错误摘要。
- 新增 API 类型和方法到 `src/api/admin/dataSharing.ts`，复用现有筛选构造逻辑和自研 `Select` 组件，不使用原生 `<select>`。

## Test Plan

- 后端单元测试：创建任务校验、筛选条件保存、状态流转、生成成功写入文件、生成失败记录错误、删除任务清理文件。
- 后端 handler 测试：列表、创建、下载完成文件、未完成/失败任务不可下载、删除幂等或明确错误。
- 仓储/迁移测试：新表可迁移，分页排序和状态筛选正常。
- 前端测试：生成按钮传入当前选择/筛选；导出文件列表渲染不同状态；完成任务触发浏览器下载；删除后刷新列表。
- 回归测试：现有数据共享列表、筛选、删除、统计不受影响。

## Assumptions

- v1 采用手动生成、一次生成一个文件、手动删除文件。
- 批量实时下载入口移除；所有管理端下载都通过预生成文件完成。
- 不新增自动清理任务；磁盘治理先由管理员在新板块手动删除。
- 生成进度先以状态和结果元数据展示，不做逐条百分比进度。
