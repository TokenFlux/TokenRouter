# 内容审核与风险处置

本文描述网关内容审核的作用域、规则优先级、同步/异步决策、风险处置和数据边界。它不定义上游供应商自己的内容政策，也不授权把完整用户内容写入普通日志。

- [规则与缓存](#规则与缓存)：修改关键词、hash、模型或 API Key 池时读取。

## 作用域与模式

审核模式为 `off`、`observe` 或 `pre_block`。规则可以覆盖全部分组或指定 Group，按 sample rate 抽样，并用 include/exclude 模式限制模型。当前协议提取器覆盖 Anthropic Messages、OpenAI Responses、Chat Completions、Gemini 和图片请求；每种协议只提取当前轮的用户文本、工具结果和允许的图片输入，避免把整段历史重复审核。

审核发生在上游调用和结算前，但身份归属与计费归属分开：团队 Key 场景使用实际行为用户作为风险主体，不能因为 owner 付款就封禁 owner。监控探测或明确标记的内部请求可按策略跳过，跳过原因应可诊断。

## 决策流水线

1. 按全局模式、分组、模型、协议和抽样率判断是否进入审核。
2. 从当前请求提取有界文本、工具输出和媒体单元，计算预审核 hash。
3. 应用阻断 hash、关键词和缓存命中；按 `keyword_only`、`keyword_and_api` 或 `api_only` 决定是否继续调用外部审核。
4. 从健康 API Key 池按优先级选择审核凭据，执行有界并发、超时和重试。
5. 根据类别阈值生成 allow、block、hash_block、keyword_block 或 error 结果，并记录审核事实。
6. `pre_block` 在上游前返回安全错误；`observe` 不阻断主请求，异步写入观测和风险结果。

多个审核单元中任一明确命中阻断即可拒绝；部分单元失败不能覆盖已经确认的阻断。没有明确阻断而审核链路不完整时，按当前模式的可用性边界记录 incomplete/error，不能伪造“已审核安全”。

## 规则与缓存

关键词、阻断 hash、类别阈值、模型过滤、分组作用域、审核 API Key 和出站代理都是运行时配置。API Key 带优先级、元数据、健康状态和冻结时间；连续失败可暂时冻结，后续健康检查或恢复时间再放回候选。代理引用管理端的 Proxy 记录，解析结果短时缓存；保存配置会立即失效本进程缓存。代理解析或客户端构建失败时不得静默回退直连，避免泄露部署真实出口地址。

预审核 hash 和规则使用缓存降低热路径成本。管理端更新后必须同时更新数据库、当前进程缓存并通知其它实例；缓存失败时的处理要保留旧规则或回源，而不能瞬间变成无规则状态。规则列表顺序和 match 模式是业务语义，禁止依赖 map 遍历顺序。

## 风险处置

审核日志可驱动按用户的命中计数，在配置的窗口和阈值达到后自动封禁；解封是显式管理动作。Cyber warning 是独立的警告计数和阈值体系，可以记录、查询和处置，但不应与内容审核 block 结果混为一个状态。风险控制启用后，管理员在 standard 与 simple 运行模式的侧栏都可进入现有风险控制页面；simple 模式不会因此获得提示词审计等未同步功能。

风险处置必须带实际用户、API Key、Group、模型、request ID、命中类别和来源规则。自动封禁失败要告警，不能把数据库更新失败当作已经阻断后续请求。管理员可查看汇总、日志、媒体、warning、API Key 测试和 unban 操作，所有敏感读取仍受管理员认证和审计约束。

## 记录与安全边界

审核记录可能包含命中文本或媒体引用，留存策略区分命中与未命中。普通 Ops/system log 只记录必要元数据、摘要和错误，不写完整 prompt、图片、审核密钥或上游原始响应。管理端展示和删除 hash/媒体时必须保持授权范围。

返回客户端的安全消息只说明请求被本地策略拒绝，不泄露关键词表、hash、阈值、供应商凭据或可用于绕过规则的细节。上游自身内容政策错误仍由平台错误分类处理，不能冒充本地审核命中。

## 失败语义

Observe 的异步队列满、worker 缺失或持久化失败不得阻断已允许的主请求，但必须累计 dropped/error 健康信号。Pre-block 的外部审核有总超时和重试上限；上下文取消立即停止。代理不可用属于外部审核错误，沿用当前模式的 fail-open 记录语义，但绝不能绕过代理改走直连。更新审核配置、API Key 池或规则缓存失败时，管理端响应不能宣称所有实例已生效。

测试至少覆盖 off/observe/pre-block、关键词/hash/API 组合、include/exclude、部分失败仍阻断、团队行为用户归属、缓存失效、多实例通知和日志脱敏。
