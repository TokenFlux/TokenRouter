# 领域文档目录

> 上级目录：[工程文档](../index.md)

## 范围

本分类记录跨多个模块维持的领域概念、业务规则、状态转换和不变量。HTTP 形状、配置键和第三方协议属于接口分类，运行流程属于运维分类。

## 文档

- [身份与租户](identity_and_tenancy.md)：用户、七类认证身份、会话、绑定、自定义属性、角色、团队和权限边界。读取时机：修改登录、OAuth、身份绑定、TOTP/Passkey、用户属性、管理员权限、团队或用户归属时读取。
- [路由与结算](routing_and_billing.md)：API Key、分组、价格配置、账号、调度、定价、配额和用量结算的关系。读取时机：修改模型路由、账号资格、分组映射、限额、价格或使用记录时读取。
- [网关策略控制](gateway_policy_controls.md)：Key、分组、价格配置、账号和全局设置的协议准入、模型路由、fallback、隐私、推理、Header 与重试边界。读取时机：修改分组策略、分组功能、账号限制或网关降级时读取。
- [用户平台额度](platform_quotas.md)：九个平台的用户日/周/月 USD 限额、预检查、结算累加、Redis 执法和数据库镜像。读取时机：修改平台额度默认值、窗口、缓存、结算或管理重置时读取。
- [支付与权益](payments_and_entitlements.md)：余额、兑换、订阅计划、支付订单、回调与权益发放不变量。读取时机：修改支付、充值、订阅、兑换码、额度包或订单状态时读取。
- [推广与返利](promotions_and_affiliates.md)：邀请码、订单返利、冻结解冻、余额转入、注册优惠码和幂等约束。读取时机：修改推广关系、返利比例/上限、支付履约赠送或 Promo Code 时读取。
- [内容审核与风险处置](content_moderation.md)：审核模式、规则/API Key 池、同步阻断、异步观测、自动封禁和安全消息边界。读取时机：修改网关内容审核、关键词/hash、风险日志或处置策略时读取。
- [API Key 模型重定向](api_key_model_redirects.md)：单 Key 模型重定向规则及其在路由和响应中的位置。读取时机：修改 API Key 模型映射、模型列表或请求/响应模型元数据时读取。
- [复合 API Key](composite_api_keys.md)：一个 Key 绑定多个分组时的前缀选组和入口限制。读取时机：修改复合 Key、前缀解析、跨分组模型或聚合模型列表时读取。
- [批量图片作业](batch_image_jobs.md)：批量图片作业的持久状态、队列、供应商执行和结算生命周期。读取时机：修改批量图片 API、worker、对象存储、状态恢复或计费时读取。
- [创作台](creative_studio.md)：个人图片生成/编辑/局部重绘任务的无素材留存生命周期、分组模型策略、隐藏执行 Key、Redis 临时数据、审核无留存与前端本地存储边界。读取时机：修改创作台 API、模型准入、worker、计费、审核留存、前端创作台或创作台配置时读取。

- [搜索编排与供应商额度](search_orchestration.md)：搜索配置发布、供应商选择、代理、额度预占及取消和停机。读取时机：修改搜索工具、Brave/Tavily 适配、额度或搜索运行时时读取。
- [通知与邮件投递](notification_delivery.md)：业务事件、模板、退订、去重、身份邮件队列及 SMTP 确认。读取时机：修改通知触发、邮件内容、投递或队列生命周期时读取。
