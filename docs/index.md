# TokenRouter 工程文档

> 本文件是 Project Doc 的根目录。当前会话加载 `project-doc` 技能后，首次处理本仓库任务时完整读取本文件，再按需求进入相关分类。之后按技能规则复用已读内容，内容缺失或需要刷新时补读。

## 文档范围

本库记录 TokenRouter 中跨层级（后端、前端、数据存储和部署）的长期工程知识。面向用户的操作指南、法律文本、生成代码、临时计划，以及看单个符号就能明白的局部实现，放在本库之外。`docs/` 下的文件需要被本目录或分类目录列出，才属于 Project Doc；`guides/` 和 `legal/` 是库外资料。

## 根级文档

- [项目总览](project_overview.md)：项目定位、仓库目录、运行形态和核心术语。读取时机：初次接触仓库、判断变更归属或需要全局上下文时读取。

## 分类

- [架构](architecture/index.md)：模块地图和依赖图、系统组成、进程启停、网关请求链路、提供商调度、缓存一致性和前端 UI 规范。读取时机：修改应用装配、服务划分、请求转发、调度快照、故障转移、前端组件或样式时读取。
- [领域](domains/index.md)：身份和租户、网关策略、计费和额度、支付和推广、内容审核、搜索、通知和后台任务的规则。读取时机：修改核心实体、业务不变量、状态转换、风险策略或结算规则时读取。
- [接口](interfaces/index.md)：HTTP 路由、配置来源、浏览器回环导入、协议能力、提供商能力矩阵、模型目录和各类上游平台的适配规则。读取时机：修改对外 API、配置项、协议转换、错误响应或第三方集成时读取。
- [运维](operations/index.md)：部署和迁移、版本升级说明、提供商和传输的维护、监控告警、开发流程和入口安全。读取时机：构建、发布、迁移、排查故障、维护数据、同步上游，或者新增、拆分、合并、改名后端 Go 文件时读取。
