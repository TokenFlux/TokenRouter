# 架构文档目录

> 上级目录：[工程文档](../index.md)

## 范围

本分类记录系统由哪些部分组成、运行时组件、依赖关系和跨模块的请求流程。具体的业务规则见领域文档，对外字段和配置见接口文档，部署步骤见运维文档。

## 文档

- [插件系统](plugin_system.md)：单实例插件安装、签名索引、版本恢复、配置密钥、进程、租约、回调、写入台账、只读权限、开发目录及信任边界。读取时机：修改插件安装管理、索引市场、更新回滚、配置、启停、回调权限或开发模式时读取。

- [后端模块地图](backend_modules.md)：后端目录、每个包的职责、静态依赖和主要模块的协作图。读取时机：查找后端代码、判断包的归属、修改模块接口或依赖时读取。
- [前端模块与依赖](frontend_modules.md)：页面私有模块、共享组件、API 类型归属、依赖检查和启动约束。读取时机：组织前端目录、移动类型或组件、修改路由装配和跨页面依赖时读取。
- [系统架构](system_architecture.md)：单实例部署、前后端整体升级，以及 PostgreSQL、Redis 和后台任务的组成、启停顺序和数据归属。读取时机：修改部署形态、进程入口、依赖注入、模块划分、静态资源交付或启动关闭行为时读取。
- [网关请求生命周期](gateway_request_lifecycle.md)：从网关入口鉴权，到选组、模型改写、提供商调度、故障转移、SSE 保活和用量结算的完整链路。读取时机：修改网关中间件、协议处理器、调度或请求的后续处理时读取。
- [提供商调度与缓存一致性](provider_scheduling_and_cache.md)：调度 bucket、提供商快照、筛选和评分、粘性和等待、数据库回退、缓存失效和认证快照。读取时机：修改调度器、快照和 outbox、提供商过滤、等待队列或缓存重建时读取。
- [前端 UI 规范](frontend_ui_conventions.md)：圆角层级、间距网格、控件尺寸、选择框、开关、菜单和浮层、筛选面板、弹窗和设置表单、全局搜索、z-index 层级、断点、加载反馈、通用图标、动效和页面过渡、行列表编辑器、表格密度、深色配色、图表主题、字体栈和字号下限，以及对应的校验命令。读取时机：修改前端组件、图标、样式、顶栏搜索、`tailwind.config.js` 或 `style.css` 时读取。
